Common questions

Good to know.

Do I need to understand Git worktrees?

No. Muxtra creates and names the branches and workspaces for you. Run muxtra status for task status in plain language.

Can agents from different providers work together?

Yes. Muxtra is designed around the repository, not a single model provider. Claude Code and Codex CLI are supported today, with more adapters planned.

Can two agents edit the same file?

They can work independently without overwriting each other. Muxtra surfaces overlapping claims and stops unsafe combinations when Git or your checks find a conflict.

Is Muxtra open source?

Yes. The Muxtra CLI is available on GitHub under the MIT License.
