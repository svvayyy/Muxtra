Privacy

Local by design.

Muxtra coordinates code on your computer. It does not need an account, an analytics profile, or a copy of your source code.

Effective August 16, 2026

The short version

No CLI telemetry

Muxtra does not send usage events, project details, prompts, or source code to Muxtra.

No website tracking added

This site does not include advertising pixels, analytics scripts, or Muxtra cookies.

Your providers stay yours

Agent and environment authentication remains between you and the providers you configure.

Information the CLI handles

Muxtra reads local repository metadata and project configuration so it can create isolated worktrees, record task state, run configured checks, and compose verified commits. This can include branch names, commit identifiers, workspace paths, process identifiers, log paths, file claims, and command output.

That operational state remains on your machine. Repository-shared state is stored in the Git common directory, while managed worktrees and logs live under ~/.muxtra/ by default. You can choose another local location with MUXTRA_HOME.

Source code, prompts, and credentials

Muxtra does not upload your repository or task prompts to a Muxtra service. When you launch a third-party coding agent, that provider may receive prompts, project context, or files according to its own product behavior and privacy terms.

The committed .muxtra/project.yaml contract is intended for commands and policy, not secrets. Environment authentication and values remain delegated to tools you explicitly configure, such as the Vercel CLI. Muxtra does not operate a credential store.

This website

Muxtra’s website is a static site hosted through GitHub Pages. Muxtra does not add analytics, advertising, form collection, or account creation. GitHub may process technical connection information required to deliver Pages, such as IP address, browser information, and request logs, under the GitHub Privacy Statement.

External links

The site links to GitHub and may link to agent providers or development tools. Their sites and applications have their own privacy practices. Following an external link takes you outside Muxtra’s control.

Changes and questions

If Muxtra later adds hosted services, accounts, or telemetry, this policy will be updated before those features are presented as active. Material changes will appear on the changelog. For questions, open an issue in the Muxtra GitHub repository.
