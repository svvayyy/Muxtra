About Muxtra

More agents should mean
more finished work.

Keep the agent interfaces you already like. Lose the workspace juggling, crossed changes, and uncertainty about what is safe to combine.

The idea

Parallelism needs coordination.

Coding agents are individually capable, but real projects rarely divide themselves into perfectly separate files. Two agents can make correct changes in isolation and still produce a broken result together.

Muxtra exists to make that coordination understandable. It gives every task room to work, shows where paths overlap, verifies the committed result, and proves the final composition before it reaches your project.

What we believe

Power without ceremony.

The machinery can be rigorous without making every user learn the machinery.

01

Git should be infrastructure

Branches and worktrees are the safety layer, not the interface. Most people should be able to describe a task and let Muxtra manage the topology.

02

Providers should coexist

Use Codex for one task, Claude Code for another, or hand a workspace to a remote client. The project—not the provider—owns the workflow.

03

Verification beats optimism

“The agent finished” is not the same as “the work is ready.” Muxtra records exact commits and reruns checks on the combined result.

04

Failure should be recoverable

Failed composition happens in temporary space. Task branches remain available. Uncommitted work is never silently discarded.

Open source

Built in the open.

Muxtra is an MIT-licensed CLI for coordinating coding agents across providers. The current release keeps each provider’s native interface intact while Muxtra owns isolation, role context, verification, and safe composition.
