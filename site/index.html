Muxtra

A Linux base for Intel Macs, built for AI agents.

Follow on GitHub See the roadmap

The hard part of Linux on a Mac is the hardware. Muxtra handles the drivers, firmware, and model quirks, then gives you and your agents a clean base to build your own OS on.

What we’re building

  1. Mac hardware, handled

    A hardware database for each Intel Mac, from older iMacs to T2 MacBooks, with drivers that are tested on real machines.

  2. Made for agents

    One manifest describes the whole system. Every module has its own folder and a clear contract, so an agent can swap parts without guessing.

  3. Proof, not diffs

    Every change builds, boots in a virtual machine, and reports what works in plain English. You read the result, not the code.

  4. Hard to brick

    A/B boot rolls back anything that breaks. Risky modules like the bootloader stay locked until you unlock them on purpose.

How it should feel

Describe the system you want. Muxtra builds it, boots it, and tells you what works.

Concept preview. The real manifest format and check output are still being designed.

Which Macs

  • Up first

    Intel Macs without a T chip

    Most iMacs, Mac minis, and MacBooks through 2017, plus the 2019 iMac.

  • Planned

    T1 Macs

    The 2016 and 2017 MacBook Pro with Touch Bar.

  • Planned

    T2 Macs

    Most Intel Macs from 2018 to 2020, including every MacBook Pro and MacBook Air.

  • After 1.0

    Apple Silicon

    M-series Macs come after the Intel release.

The road to Aphelion

Aphelion is the point in an orbit that’s farthest from the sun. It’s also the codename for Muxtra 1.0.

  1. Phase 1 Now

    Skeleton

    One manifest, swappable modules, and a check that boots everything in a virtual machine.

  2. Phase 2

    Real Macs

    USB boot on real hardware. Macs without a T chip first, then T1, then T2.

  3. Phase 3

    Agent box

    A headless build with SSH and remote access, ready for coding agents out of the box.

  4. Phase 4

    Safety net

    A/B boot with automatic rollback, and locked modules for the risky parts.

  5. Release

    Aphelion

    The first beta release, for Intel Macs.
